# Claude Marketplace

## Adding a New Plugin

Create only:

```text
plugins/<name>/.claude-plugin/plugin.json
```

Everything else is automated:

- `marketplace.json` - synced by CI
- `release-please-config.json`, `.release-please-manifest.json` - generated by CI
- Version bumps - handled by Release Please

Constraints:

- Directory name must equal `plugin.json` `name`. Otherwise release config silently skips the plugin (warning only) and it never bumps.
- Removing a plugin: delete its `marketplace.json` entry manually. Sync only adds/updates.

## plugin.json Template

```json
{
  "name": "plugin-name",
  "version": "0.1.0",
  "description": "What this plugin does",
  "author": {
    "name": "Amir Arad",
    "email": "greenshade@gmail.com"
  },
  "keywords": ["relevant", "tags"]
}
```

## Commit Convention

Use conventional commits for automatic versioning:

- `feat:` → minor bump
- `fix:` → patch bump
- `feat!:` or `BREAKING CHANGE:` → major bump

Each plugin versions independently: a commit bumps only plugins whose directories it touches.

Squash-merge: the PR title is the commit Release Please reads, so it needs the prefix. If a Release PR never opens, remove any stale `autorelease: pending` label from old PRs.
